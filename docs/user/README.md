## About these guides

- Screens are shown as of version 1 of the app (November 2026). Names and button labels are copied from the screen in capitals, the way the app prints them.
- Some screens behave in ways that are being fixed. Where that affects you, you will see a box titled **Current limitation**. The documentation team removes each box once the fix is released.
- Screenshots have personal details blacked out.
